# Local input-buffer measurement storage

[日本語・正本](README.md) / [Measurement commands](../../docs/input-buffer-measurement.en.md)

This folder holds originals within this project. **Only this README and its translation are tracked; run folders are Git-ignored.** No real measurement data exists yet.

- Use the procedure to create `ibuf-001/`, with `sessions/`, `analysis/`, `photos/`, `review/` and record notes.
- Never delete or overwrite runs. Use new names for repeated captures and new IDs for separate runs.
- Original ZIPs contain waveform CSVs, a screen PNG and settings/readings in `manifest.json`.
- Do not enter IPs, serials or personal data into notes. Images and metadata are not automatically masked.
- After review and user authorization, copy selected material to [public evidence](../../docs/evidence/input-buffer/README.en.md).
- Do not force-add runs to Git. Keep a separate backup of ignored originals.
