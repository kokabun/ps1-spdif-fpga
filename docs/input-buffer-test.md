## テスト概要

PCでの測定・保存には[DHO914S CLIのコマンド付き手順](input-buffer-measurement.md)を使う。原本・解析・記録メモは本リポジトリ内へ保存し、公開資料と分離する。試験回路と判断条件の正本は本書。

LCX541は信号を受けて次へ送り出すIC（バッファ）。出力を有効にすると、入力がLow（0 V付近）なら出力もLow、High（今回なら3.3 V付近）なら出力もHighになる。この「0/1を逆にしない」動作を**非反転**と呼ぶ。

### なぜバッファICを使うのか

**PS1の0/1信号を受け取り、Nano側の3.3 V系の信号としてFPGAへ渡すため。** FPGA入力には扱える電圧範囲があり、現在のPS1取り出し配線では、負側への振れや信号の変化の速さの確認が残っている。このPoCでは[バッファ経由の構成を評価する方針](ps1-input-interface.md#採用方針)としている。

- **電圧を合わせる：** LCX541は3.3 Vで動かしながら、仕様範囲内で最大5.5 Vの入力を受け、0/1を3.3 V系の出力として送り出せる。これは「PS1の信号が5 V」と確定した意味ではない。
- **FPGA側を駆動する：** FPGA側の配線や入力へ信号を送り出す役割をLCX541が担う。PS1からICまでの配線の影響や、IC入力の負荷は残る。
- **出力を止められる：** `/OE`で出力を有効・無効に切り替えられるため、書込みや試験の段階に合わせてFPGAへ信号を送る状態を管理できる。

これらの機能・条件は[東芝データシート](https://toshiba.semicon-storage.com/info/74LCX541FT_datasheet_en_20181030.pdf?did=15179&prodName=74LCX541FT)の§2・8・10・11に基づく。LCX541自身にも入力電圧・変化速度の制限があり、**負電圧などへの追加保護が必要かは別途確認する。** `/OE`を無効にしても入力の過電圧は防げない。

バッファの採用は今回の設計方針で、すべてのPS1改造にこのICが必須という意味ではない。音声をS/PDIF形式へ変換するのはFPGAの役割。

### 今回先に確かめること

まず、実装したLCX541が0/1を正しく送り出し、出力を有効・無効にできるかを確かめる。今回の3.3 V信号での単体試験だけでは、PS1側の電圧への適合までは確認できない。

PS1の代わりにNano 9Kから試験用の信号を出し、ICの入口と出口をオシロスコープで見比べる。使用機種はDHO914S。

```text
Nano 9K（USB給電・専用試験イメージ）
  FPGA 29の試験出力 → LCX541 A1 → Y1 → オシロスコープのみ
  3V3 / GND        → LCX541電源

PS1：全線を外す    光送信モジュール：全線を外す
LCX541出力 → FPGA入力：まだ接続しない
```

| 順番 | 何をする？ | 正常ならどうなる？ |
|---|---|---|
| 1. 配線・電源を確認 | 電源を切って配線を確認し、その後テスターで電源電圧を測る | ICに約3.3 Vが届く。短絡や異常発熱がない |
| 2. 一定の電圧で確認（静的試験） | 入力を0 V、3.3 Vにして、それぞれ出力を測る | 出力有効時は入力に対応してLow、Highになる。無効にすると抵抗によりLowへ戻る |
| 3. 波形で確認（動的試験） | Nanoから0/1を繰り返す信号を入れ、CH2で入力、CH3で出力を見る | 出力有効時は同じ速さで変化する波形が出る。出力にはわずかな遅れがある |

この表は全体像。実際の接続・切替は後半の[試験手順](#試験手順)に従う。初回は既定の**約2.7 MHz**（1秒に約270万周期）で確認し、写真1枚と周波数・電圧を残すところまでを目安にする。精密な遅延測定や高速の追加試験は後日でよい。

ここで分かるのは組立と基本動作。**音声が正しく取り出せるか、PS1を接続してよいかは別の確認が必要**で、保護回路もまだ最終確定していない。

## 配線

### 電源を外して組み立てる

下図は**A1だけを使う単体試験**。部品面のIC端子番号であり、変換基板の穴番号ではない。変換基板の0.65 mm側とICの1番マークを照合し、はんだブリッジ・隣接端子との短絡・各ランドの導通をテスターで確認する。接続を変更するときはUSBも外す。

ブレッドボード上の部品位置と今回接続する範囲は[ブレッドボード構築イメージ](ps1-input-interface.md#ブレッドボード構築イメージ)を参照する。Nanoはブレッドボードへ直接挿さず、下図のFPGA29→Rs→Rinと3V3/GNDだけをジャンパ線で接続する。

![PS1未接続のLCX541単体試験配線](images/lcx541-standalone-test.svg)

図の部品番号は[番号付きブレッドボード配置図](ps1-input-interface.md#部品番号の対応表)と共通。U1＝LCX541、R1＝Rs、R2＝Rin、R3＝Rpd、R4＝Rout、R5＝Rhold、R6＝/OE用10 kΩ、C1＝Cdec、C2＝Cbulk、JP_EN1＝SW_ENABLE。TP1/TP2＝TP_A/TP_Y、TP3/TP4＝GND測定点。配置更新後の出力測定点は**J17**で、旧図のJ3ではない。

図は上段が「信号の通り道」、左下が「電源」、右下が「出力の有効／無効の切替」。[拡大表示](images/lcx541-standalone-test.svg)で文字を確認できる。部品位置は概念図で、実寸配置図ではない。

| 図の記号 | 読み方・役割 |
|---|---|
| `A1` / `Y1` | ICの入力／出力。括弧内の数字はIC端子番号で、変換基板の穴番号ではない |
| `TP_A` / `TP_Y` | プローブの先端を当てる測定点。CH2＝入力、CH3＝出力。配置図の`TP_A1` / `TP_Y1`と同じ点 |
| `3V3`・`VCC` / `GND` | 3.3 V電源・ICの電源端子／電圧の基準（0 V）。図のGNDは全て共通につなぐ |
| `/OE1`・`/OE2`、`SW_ENABLE` | 出力を切り替える端子とジャンパ。ジャンパを外すと無効、GNDへつなぐと有効。ICの電源自体は切れない |
| `Hi-Z` / `NC` | Hi-Z＝出力がHighもLowも駆動しない状態。NC＝何もつながない端子。どちらも「GNDへ直結」の意味ではない |

`Rs`・`Rin`・`Rout`は信号線に入れる抵抗、`Rpd`・`Rhold`は信号が駆動されないときに電圧をLowへ寄せる抵抗（プルダウン）。`Cdec`・`Cbulk`は電源の揺れを抑えるコンデンサ。値と置き場所は次の表に従う。

| 接続先 | IC端子番号 / Nano接続先 | 接続 |
|---|---|---|
| VCC | LCX541 **20** | Nanoの基板表示`3V3`（公式図面J6-24）。**5Vを使わない** |
| GND | LCX541 **10** | Nanoの基板表示`GND`（公式図面J6-23）。同じ基準へ全GNDを接続 |
| `/OE1`, `/OE2` | LCX541 **1, 19** | 両方を共通`/OE`へ。10 kΩで3V3へプルアップし、着脱ジャンパ（またはスイッチ）でGNDへ。初期は開く |
| A1 | LCX541 **2** | Nano FPGA **29**（J5-9）→ Rs 33 Ω → Rin 100 Ω → A1。RsはNano直近、RinはIC直近 |
| A1の弱いプルダウン | LCX541 **2**とGND間 | Rpd 100 kΩ。TP_AをA1端子直近に配置 |
| Y1 | LCX541 **18** | Rout 33 Ω → TP_Y。TP_YからRhold 100 kΩ → GND。**FPGAへ戻さない** |
| 未使用A2～A8 | LCX541 **3～9** | 全てGNDへ。入力を浮かせない |
| 未使用Y2～Y8 | LCX541 **17～11** | 全て未接続。GNDへ短絡しない |
| Cdec | LCX541 **20–10**間 | 0.1 µF、定格10 V以上、端子直近・最短配線 |
| Cbulk | 入力基板の3V3–GND間 | 1 µFセラミック、定格10 V以上、電源入口 |

**J5/J6番号を、USBから見た穴の数え方で推定しない。** 公式回路図のコネクター番号と実物のシルク・基板版を照合する。向きや3V3/GNDを同定できない場合は給電せず確認する。基板上27 MHzはFPGA端子52へ既に配線されており、外部ジャンパは不要。

Rs/Rin/Routは評価開始値であり、負電圧クランプではない。Rsは今回のNano試験信号源に追加する抵抗で、最終PS1回路の部品追加を意味しない。信号とGNDは短く近接させる。変換基板を長いジャンパ線でつないだ状態の高速測定を、最終実装の保証としない。

### ICの向きと後日の4信号割当

東芝データシート§5の端子配置図を画像で照合した。IC上面から見た対応は以下のとおり。実物の1番マークを必ず確認する。

```text
             74LCX541FT 上面
          ┌──── 1番側 ────┐
  /OE1  1 │              │ 20 VCC
    A1  2 │              │ 19 /OE2
    A2  3 │              │ 18 Y1
    A3  4 │              │ 17 Y2
    A4  5 │              │ 16 Y3
    A5  6 │              │ 15 Y4
    A6  7 │              │ 14 Y5
    A7  8 │              │ 13 Y6
    A8  9 │              │ 12 Y7
   GND 10 │              │ 11 Y8
          └──────────────┘
```

後日の4信号案はMCLK候補=A1(2)→Y1(18)、BCK=A2(3)→Y2(17)、LRCK=A3(4)→Y3(16)、DATA=A4(5)→Y4(15)。**この試験ではPS1もNanoの入力端子25～28も未接続**。単体試験をA2～A4へ繰り返す際は、電源OFFで対象AのGND直結を外して試験入力とRpdを移し、元のAをGNDへ戻す。対応するYへRout/Rholdと測定点を移す。出力同士を結ばない。

## ビルド

### シミュレーション

リポジトリ直下で実行する。

```sh
make test-input-buffer
make test
```

前者は試験信号源のみ、後者は既存PCM RX・FIFO・S/PDIF等の回帰試験も実行する。LCX541のアナログ特性や実物の配線はシミュレーション対象外。

### 試験信号の設定（初回は変更不要）

既存のS/PDIFプロジェクトとは独立した試験プロジェクトを使う。PLLは使わず、基板上の27 MHz発振器の信号を整数分周して遅くする。音声PCMやS/PDIFの試験信号を生成するものではない。

| `HALF_PERIOD` | 公称出力周波数 | 使い方 |
|---:|---:|---|
| 5（既定値） | 2.7 MHz | 最初の動的確認。PS1のBCK 2.8224 MHzそのものではない |
| 306 | 約44.117647 kHz | 低速の確認用。正確な44.1 kHzではない |
| 1 | 13.5 MHz | 配線を短く整えた後の任意の追加確認 |
| 0 | 27 MHz | 分周なし。任意の追加確認、起動待ち中も出力する |

分周時の理論dutyは50%（HighとLowの時間が半分ずつ）。周波数精度は搭載発振器に従い、実際の端子波形のduty・遅延・振幅は別途測定する。負値は設定しない。

**13.5 MHzと27 MHzはMCLK相当の正確な16.9344 MHzを代用・保証しない。** 27 MHzまで通っても、PS1の入力傾斜、負電圧、配線負荷、4信号間の遅延差、電源遷移が合格したことにはならない。高速試験を初日に終える必要はない。

### Gowin EDAと書込み

1. **PS1、光送信モジュール、Nanoのその他の外部回路を全て外す。** 最初の書込みはNanoだけで行う。
2. `platform/tang_nano_9k/input_buffer_test/input_buffer_test.gprj`を開く。既存の`ps1_spdif.gprj`ではない。
3. Deviceが実装品に合う`GW1NR-LV9QN88PC6/I5`、topが`input_buffer_test_top`であることを確認する。プロジェクトには試験用の2つのVerilogファイルだけが入る。
4. 既定値は2.7 MHz。変更するときはこの試験フォルダーの`top.v`にある`HALF_PERIOD`既定値だけを上表から選び、毎回合成・配置配線をやり直す。PLL IP生成は不要。`STARTUP_BITS`は16のまま使用する。
5. Synthesize、Place & Routeを実行し、エラー・警告を確認する。配置レポートで**入力52、出力29、いずれもLVCMOS33**、出力DRIVE=4を照合する。未使用I/O設定も確認する。不要な外部配線を外す方針は設定で代替しない。
6. SDCは27 MHz入力クロックのみを定義する。外部同期受信器がないので出力のsetup/holdは指定していない。I/O経路や出力波形の保証は未完了。入力クロックを認識したこと、内部タイミング違反、clock-to-pad経路、未制約経路の理由をレポートで確認する。未確認のまま「タイミング合格」と記録しない。
7. Programmerで認識された対象を照合し、**SRAM書込み（SRAM Program等の表記）**を選ぶ。生成した試験プロジェクトの`.fs`を選択する。操作名はバージョンにより異なる。Flash消去・Flash書込みはこの試験では行わない。
8. オシロスコープでNano単体の出力を確認してから、電源OFFで入力基板を追加する。USBを抜くとSRAMの試験イメージは失われるため、**再給電時は/OEを開いたまま、再び試験イメージを書き込む**。既存Flashのイメージが起動し得るので、それを試験信号と取り違えない。

周波数設定・生成日時・使用した`.fs`を作業メモに残す。試験イメージをロードしたままPS1や光送信モジュールを接続しない。通常PoCへ戻すときは電源OFFで配線を取り外し、通常プロジェクトへ切り替え、入力接続条件を改めて確認する。

## 試験手順

以下の有効／無効切替を通電中に行う場合は、図のSW_ENABLEを無通電時に配線・固定したスイッチとして用意する。着脱ジャンパJP_EN1しかない場合は通電中の抜き差しで代用せず、切替方法を確認してから進む。配線変更・電源投入・書込み時はOPENとし、動的試験は再給電ごとに専用SRAMイメージを再書込みする。

### 1. 無通電の確認と3V3

- Nano・入力基板とも無通電で短絡、ICの向き、未使用入力のGND接続、/OEの10 kΩプルアップを確認する。低抵抗のままなら給電しない。
- /OEの着脱ジャンパを外し、FPGA出力→A1はまだ外しておく。Nano 3V3/GNDから入力回路だけを給電する。他の電源は接続しない。
- テスターでIC 20–10間が3.3 V系の設計範囲（今回の評価では3.0～3.6 V）にあること、/OEがHighであることを確認する。異常発熱、電源低下、想定外の電圧があれば直ちに電源OFF。電流計を電源へ並列接続しない。

### 2. 静的0/3V3と/OEの確認

この段階ではNano試験出力をA1につながない。電源OFFで、Rinの信号源側をGNDへ、次に3V3へ切り替えて試す。**試験出力ピンと3V3/GNDを同時に結ばない。**

| A1 | /OEジャンパ | TP_Yの期待状態 |
|---|---|---|
| GND | 閉（有効） | Low |
| 3V3 | 閉（有効） | High |
| 3V3 | 開（無効） | 出力はHi-Zとなり、Rholdにより時間を置くとLow |

切替直後のRC過渡を待つ。最後のLow表示だけではHi-Zを厳密に証明しないが、有効時にHighへ戻ることと合わせて初期の配線・/OE動作を確認できる。出力へ直接電源を当てて試さない。

### 3. 約2.7 MHzの動的確認

1. 電源OFFで静的試験の3V3/GNDジャンパを外し、Nano FPGA29→Rs→Rinを配線する。**まずA1端子だけは切り離した状態**で、Rin後・Rpd付きの信号源波形を測定する。再給電後に専用イメージを書き込み、周波数と振幅を確認する。想定外の振幅・負側振れがある場合はLCX541につながず調査する。
2. 電源OFFでA1へ接続し、/OEを開いたまま再給電・再書込み。オシロスコープのCH2をTP_A、CH3をTP_Yへ接続する。**両チャンネルのプローブ物理スイッチと本体設定を10Xに一致**させる。別のチャンネルを使ってもよいが記録する。
3. GNDクリップは入力基板GNDだけに接続する。オシロスコープのチャンネルGNDは共通として扱い、信号端子へ挟まない。商用電源側には触れない。
4. DC結合、1 V/div、時間軸100 ns/div程度、トリガーCH2立上り・約1.5 Vから開始。表示位置を調整し0～3.3 Vの全体を表示する。AUTOは表示を得る補助として使い、実行後にCH・10X設定・帯域制限を再確認する。
5. /OEを閉じて、有効時のTP_YがTP_Aと同じ論理で遅れて変化すること、周波数が約2.7 MHzであることを確認する。/OEを開いてTP_Yが弱いプルダウンでLowへ落ちることも確認する。
6. まず写真1枚と周波数・High/Low・Vmax/Vminを残す。時間差の精密測定は初回の必須ではない。高周波の振幅・立上りを見る際は帯域制限OFFを使い、ピークが疑わしければ近接した短いGND接続で再確認する。測定器の接続に由来する波形と実際の逸脱を区別する。

判定の目安：LCX541入力の推奨範囲0～5.5 V、VIH≧2.0 V・VIL≦0.8 V。将来のFPGA入力はLVCMOS33の通常範囲-0.3～3.6 V、VIH≧2.0 V・VIL≦0.8 Vと照合する。**平均電圧やVppだけで合格にしない。** 負電圧や過大ピークが見える場合、絶対最大定格まで使用可能という意味に読み替えず、波形・持続時間・測定条件を確認する。

入力傾斜は東芝の条件（VCC=3.0 V、VIN=0.8～2.0 Vで0～10 ns/V）と照合する。オシロスコープの標準Rise Time（通常10–90%）と区間が異なるので、その値をそのまま合否基準へ代入しない。

### 4. 任意の追加試験

必要なら約44.118 kHz、13.5 MHz、27 MHzへ設定変更して再ビルドする。目安の時間軸は順に5 µs/div、20 ns/div、10 ns/div。高速側はプローブ負荷・GNDリード・配線長の影響が大きい。短い配線と測定条件を整えられなければ後回しにする。

伝搬遅延を見る場合は入力・出力の同じ電圧点をカーソルで比較し、プローブ間skewも考慮する。データシートの1.5～6.5 nsは指定電源・負荷・波形条件での値であり、この治具に直接適用した保証値ではない。
