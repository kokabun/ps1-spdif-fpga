# 入力バッファ単体試験の公開エビデンス

[English](README.en.md) / [測定手順](../../input-buffer-measurement.md) / [試験概要](../../input-buffer-test.md)

このフォルダは、**公開前確認が完了した結果と資料だけ**を置くGit管理対象。実測結果はまだ登録していない。手順・模擬テスト成功を実機試験の成功と混同しない。

## 構成

測定runごとに `ibuf-001/` などを作り、次を選別して格納する。

- `README.md`：日本語の結果表、条件、判断根拠、残る未確認事項。
- `README.en.md`：用意できる場合の英訳。双方の冒頭に言語リンク。
- `enabled.png` / `disabled.png` など：確認済みの測定画面。
- 配線写真・波形抜粋等：必要性と公開範囲を確認したものだけ。

原本・解析の作業用データは[ローカル保存先](../../../captures/input-buffer/README.md)へ置く。既存のPU-20測定画像は移動・置換しない。

## 登録前チェック

- [ ] 対象run、回路・FPGA・ツール版、測定条件、測定点を記載した。
- [ ] 「確認できた」「要再測定」「未実施」を区別し、単体動作だけでPS1接続許可を出していない。
- [ ] 画像本体・メタデータ、CSV、JSON、解析文、コメントとファイル名を確認した。
- [ ] IP、シリアル、個人情報、ローカル絶対パス、私的な記録を含まない。
- [ ] 公開する内容と範囲についてユーザーの承認を得た。
- [ ] 必要なファイルだけを選び、差分と容量を確認した。

生ZIP・全CSVは既定では登録しない。追加する場合は内部ファイルも全て点検する。コミットとpushは測定とは別の承認手順で行う。
