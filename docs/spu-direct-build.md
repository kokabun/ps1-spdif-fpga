## ユニバーサル基板への配置イメージ

![光送信基板の部品配置・配線イメージ](spu-direct-layout.svg)

[拡大できるSVG配置図](spu-direct-layout.svg)。第一候補のAE-3G（72×47.5mm）を想定した概念図であり、穴番号を指定する実装図ではない。
PLT133/T10Wを光コネクターが基板外向きになる端へ置き、接続用J1と信号切離し用JP1を反対側へ置く。
C1はU1のVcc–GND端子へ最短で配置する。C2は電源入口寄り、R1はVin–GND間に配置する。

チェック端子は4点とする。

| チェック端子 | ネット | 測る内容 |
|---|---|---|
| TP1 | 3V3 | 無負荷・U1動作時の電圧、電源変動 |
| TP2 | GND | 全測定の基準。TP4の近くに置き、プローブGNDを短くする |
| TP3 | SPDIF_SRC | JP1よりFPGA側。FPGA出力だけを確認 |
| TP4 | SPDIF_VIN | JP1よりU1側。U1を接続した状態の波形を確認 |

部品面から見た配置と、配線面を部品面から透視した図を併記している。
実際に基板裏側を見て配線すると左右が反転するため、印刷した図をそのまま裏面の穴位置へ写さない。
導通確認では、図の色ではなく接続表を正本とする。未使用穴を信号間に残し、裸線同士を交差させない。
基板の型番が確定したら、実穴数、取付穴、PLT固定脚、J1の向きに合わせた穴番号付き実装図へ更新する。

## Tang Nano 9K側のブレッドボードPoC

まずPS1を接続せず、Nanoの書込み・出力ピン・電圧を確認し、その後に光送信基板を接続する。
Nano本体は絶縁した台へ固定し、実装済みオスヘッダーから短いジャンパーワイヤでブレッドボードへ引き出す構成とする。
ブレッドボードへ本体を直接挿す場合は、ヘッダー間隔、空き穴、裏面部品の接触を現物で確認する。以下は穴番号を指定する実装図ではない。

Dupont線は2.54mmピンヘッダー等に使うジャンパーワイヤの通称。
**メス–オス**はNanoのオスヘッダーとブレッドボード、**オス–オス**はブレッドボード内、**メス–メス**は両側がオスヘッダーの基板間に使う。
端子の性別は現物に合わせる。既存表のメス–メス線だけでは、ブレッドボードの穴へ直接挿せない。
線色だけに頼らず両端へネット名を付け、信号とGNDを近接させて短く配線する。ブレッドボードとジャンパーの寄生成分を含めて実測する。

### 出力の配線と33Ωの比較

```text
Nano FPGA29 / J5-9 (spdif_out, LVCMOS33)
  │
  ├─ TP-A（抵抗よりFPGA側）
  │
  └─ [短絡ジャンパー または Rs=33Ω] ─ TP-B ─ 光基板 J1-3 / TP3
      Nano出力直近、電源OFFで交換                     │ SPDIF_SRC
                                                   JP1（初期OPEN）
                                                     │ SPDIF_VIN
                                                     ├─ TP4 ─ U1-1 Vin
                                                     └─ R1=10kΩ ─ GND

Nano 3V3 ─ 光基板 J1-1 / TP1 ─ U1-2 Vcc
Nano GND ─ 光基板 J1-2 / TP2 ─ U1-3 GND（共通GND）
U1-2 ─ C1=0.1µF ─ U1-3（端子直近、必須）
U1-2 ─ C2=10µF  ─ U1-3（任意、＋はU1-2）
U1-4 / U1-5：NC、未接続
U1 PLT133/T10W ─ TOSLINK ─ 光入力DAC／アンプ
```

FPGA29はFPGAのパッケージ端子番号、J5-9はNanoヘッダー番号であり、「ヘッダーの29番」ではない。
既存CSTの`spdif_out`は29、LVCMOS33、DRIVE=8。電源は本書の設計どおりNanoの**3V3**を用い、USBの5Vを光基板の3V3ネットへ接続しない。
PLT133/T10Wの端子番号・推奨電源範囲・C1は下記メーカー資料と照合済み。メーカー測定回路の5V表記を本PoCの給電指示として転記しない。
実装時の端子の左右はデータシートの視点と現物で確認する。

Rsは既存回路図では未実装。まず短絡ジャンパーで導通させ、必要時に33Ωへ交換して比較する。抵抗もジャンパーもない開放状態を「抵抗なし」としない。
Rsを長い引出し線の末端に置かず、Nano出力直近へ配置する。33Ωは確定した終端値ではなく、レベル変換・過電圧保護・75Ω同軸S/PDIF出力回路の代用にもならない。
TP-BとTP3は同じネットだが物理位置が異なる。必要に応じて受信端TP4でも波形を確認する。
R1=10kΩはJP1よりU1側のVinプルダウンであり、TP-Aへ移したり追加したりしない。

### 測定手順と記録

1. 電源OFFで3V3–GNDの短絡、ヘッダー位置、ブレッドボードの導通、U1端子、C2極性を確認。JP1はOPEN、PS1入力は未接続とする。
2. Nano単体で書込みと出力方向を確認する。PS1信号がない状態で既存RTLから有効な音声S/PDIFが出るとは仮定しない。動的波形の比較には、入力未接続でも動作する検証用信号源／FPGA構成が別途必要となる。
3. 電源OFFで光基板の3V3・GND・信号を接続。TP1をTP2基準で測り、電圧と起動時変動を確認する。Nano・ブレッドボード・光基板のGNDを共通化する。
4. 出力電圧確認後、電源OFFでJP1を閉じる。TP-A、TP-B、TP3、TP4を近傍GND基準で測る。プローブGNDを短くし、High/Low電圧、立上り／立下り、オーバーシュート／アンダーシュート、リンギングを記録する。
5. 電源OFFで短絡ジャンパーを33Ωへ交換し、同じ信号・配線長・プローブ条件で再測定する。光入力機器のロックと音声確認は、有効なS/PDIFフレームを出せる段階で行う。

測定記録にはFPGA構成、Rsの有無、JP1状態、負荷、3V3実測値、測定点、配線長、プローブ倍率・帯域設定を残す。書込み前には電源OFFでJP1をOPENへ戻す。

### PS1入力側は実測後に確定

既存CST上の割当はWCKO（MCLK）=FPGA25/J5-5、BCKO=26/J5-6、LRCO=27/J5-7、DATO=28/J5-8。
これは接続先候補であり、PS1からの直結許可ではない。
2026-09-06の測定ではLRCO 44.097 kHz、BCKO 2.8225 MHz（約64 Fs）を確認した。ConsoleMods表記MCLKでは16.806 MHzを撮影し、直前に16.949 MHzも観測したが、公称16.9344 MHz、384 Fs、WCKOとの同一性はまだ確定しない。
音楽CD再生中の単一取得ではDATOがBCKO立下り付近で遷移し、立上りcaptureを第一候補としたが、probe間skew、正確なsetup/hold、slot境界、bit位置は未確定である。
測定写真・条件・peak読値の扱いは[READMEの実機測定記録](../README.md#lrco--bcko--dato--mclk測定のエビデンス2026-09-06)を参照する。
PS1信号のHigh/Low電圧、周波数、立上り／立下り、オーバーシュート、左右極性、データ境界と電源順序を実測してから、バッファ・レベル変換・保護素子とその電源を選定する。
TC74HC4050AP等の特定部品は現時点で確定しない。入力側のGND・取り出し点も現物で確認し、未確定インターフェースをジャンパーでバイパスしない。

既存SVGは光送信基板の配置・回路図として上記の相対参照を維持する。追加のブレッドボードPoC配線は本節を正本とする。
照合資料：[既存CST](../platform/tang_nano_9k/tang_nano_9k.cst)、[Sipeed公式回路図](https://dl.sipeed.com/fileList/TANG/Nano%209K/2_Schematic/Tang_Nano_9k_3672_Schematic.pdf)、[Everlight PLT133/T10W Rev.5](https://www.everlighteurope.com/custom/files/datasheets/DPL-0000049.pdf)。確認日：2026-09-05。


## 光送信側の接続表

| ネット | 接続する端子 |
|---|---|
| 3V3 | J1-1、U1-2 Vcc、C1片側、C2＋（実装時） |
| GND | J1-2、U1-3、C1もう片側、C2−（実装時）、R1片側 |
| SPDIF_SRC | J1-3（Nano FPGA29 / J5-9から）、JP1-1 |
| SPDIF_VIN | JP1-2、U1-1 Vin、R1もう片側 |
| NC | U1-4、U1-5：GND等へ結線しない |

J1の番号は**今回の小基板で新規に定義した番号**であり、Tang Nanoのヘッダー番号ではない。
J1-1/J1-2のNano側接続点は公式回路図と現物表示で3V3/GNDを特定する。PS1電源から給電しない。
JP1は信号だけを切り離す手動部品。電源・GNDの切断、自動保護、PS1側の絶縁機能はない。

## 値と回路の根拠

- **メーカー資料**：PLT133/T10Wは推奨電源2.7〜5.5V、端子1=Vin、2=Vcc、3=GND、4/5=NC。回路例に0.1µFを使用。C1はU1の電源端子間へ最短で配置する。長い線の先のコンデンサでは代用しない。[Everlight Rev.5、2〜4ページ](https://www.everlighteurope.com/custom/files/datasheets/DPL-0000049.pdf)
- **今回の設計提案**：Nanoと光送信機を同じ3.3V系統で給電。メーカーの消費電流上限10mAは表の試験条件Vcc=5V等に基づく値であり、Nano全体の供給余力を証明しない。追加負荷・起動時の電圧・電源順序は実測する。
- **今回の設計提案**：C2=10µFは補助。必須のメーカー指定ではなく、配線や電源変動に応じて使う。C1は省略しない。
- **今回の設計提案**：R1=10kΩはJP1開放時／FPGA高インピーダンス時にVinを浮かせないため。3.3V High時の負荷は約0.33mA。FPGA内蔵pull-up等と競合しないか起動時に測定する。Lowを保証する自動保護回路ではない。
- **メーカー資料＋運用**：VinとVccの電源OFFを揃える。JP1は初期OPEN。書込み前は電源OFFでOPENへ戻す。最初はNanoだけで書込み、ピン方向・信号電圧を確認してから、電源OFFで光基板を接続／JP1を閉じる。通電中の差替えはしない。

## SPU側を完成させる条件

図のCXD2925Q 97/98/99/100は[第三者ピン資料](https://psx-spx.consoledev.net/pinouts/)に基づく候補。Sony一次資料や現物導通による確定ではない。
まず電源基板には触れず、対象PU-20の安全な取り出し点とGNDを確認する。端子へはんだ付けする前に、電圧、周波数、エッジ、左右極性、16-bit RJ境界を確認する。
測定後、保護・変換回路、配線材、取り出し点、CST/SDCを確定する。測定前のバイパス線は設計しない。
Nano入力25〜28、光出力29は[既存CST](../platform/tang_nano_9k/tang_nano_9k.cst)と[Sipeed公式回路図](https://dl.sipeed.com/fileList/TANG/Nano%209K/2_Schematic/Tang_Nano_9k_3672_Schematic.pdf)が根拠。クロック配線資源の配置配線検証は別途必要。

通電前にC2極性、U1端子の表裏、電源短絡、NC端子、JP1開放をテスターで確認する。光送信回路の製作と電圧・信号試験が完了しても、未測定のPS1へ接続する根拠にはならない。
