# 直結PoCへの共通RTL修正の反映

[English](rtl-backport.en.md) / [README](../README.md)

2026-09-04。日本語を正本とする。

## 出典と範囲

`ps1-pio-lab-pcb`の統合コミット`793d647`にある`fpga/spdif/rtl/`の共通修正を、
本PoCへ選択的に反映した。元PoC由来のMIT RTLを修正して戻す作業であり、
PIO基板プロジェクト全体のマージやライセンス変更ではない。
同コミットのFIFO試験・統合試験・出力復号スクリプトも直結条件に限定して適合させた。
基板固有CST、PIOトップ、設定生成器、768Fs/6周期機能は取り込まない。

## 反映した修正

- `async_fifo.v`：満杯状態をレジスタ化し、次ポインタ経由の組合せループを解消。
- `spdif_tx.v`：16-bit PCMをbit 12〜27へ配置。左は受け付けるペアから、右は保存した
  同じペアから選択し、readyとFIFO消費エッジを一致させる。
- 枯渇時は左右を0にしてValidity=1。完成ペイロードから偶数パリティを生成。
- プリアンブルを直前出力の極性に対して生成。旧固定極性が常に誤りだったという主張ではない。
- `ps1_pcm_rx.v`：reset後の途中スロットを除外し、境界と16 bit以上を観測した完全な左右ペアから開始。
- `ps1_spdif_core.v`：選択した受信エッジにFIFO書込み・overflow検出も統一。
- `reset_release.v`：非同期assert、クロックドメイン別の同期解除。両ドメインを共通resetで初期化する。
- Gowinプロジェクトのソース一覧にresetモジュールを追加。9K top、PLL wrapper、CST/SDCは変更しない。

384Fs入力と3周期ごとのhalf-bit更新は維持する。実機のエッジ・極性・電圧を確定したものではない。

## 検証と限界

`make -B test`で既存単体2件、FIFOテスト、直結8条件がPASS。
8条件はエッジ2種×左右極性2種×スロット16/32 bit。各条件で419組の左右PCMを
出力S/PDIFから復号し、連番の欠落・重複・並べ替え、音声位置、左右対応、偶数パリティ、
U/C、Z/X/Yと極性、192フレーム境界、枯渇時ミュート/Validityを確認する。
FIFOは4エントリ容量、満杯書込み拒否、順序、周回、resetを検証する。
旧単体テストの失敗終了を`$fatal`へ変更し、失敗が終了コードへ反映されるようにした。

従来の単体2件PASSだけではこれらの正しさを示せなかった。
今回もIEC 60958全適合、非同期入力の全位相、実機の電源・信号品質・光ロックを保証しない。
クロック停止監視、未知の入力形式、未測定の遅延への対応は未追加。
Gowin合成・配置配線は未実行。timescale継承警告は残る。
